## 🌡️ 4月杭州气候总体特征

4月是杭州的**春雨旺季**，气候温和但雨水较多，早晚温差较大。

---

## 📊 4月中旬具体数据（4月15日参考）

### 气温

| 时段 | 温度范围 | 说明 |
|------|---------|------|
| 白天平均最高气温 | **20–22°C**（68–72°F） | 阳光充足时较暖和 |
| 夜间平均最低气温 | **11–13°C**（52–55°F） | 早晚较凉，需添衣 |
| 全月趋势 | 逐渐升温 | 4月上旬较凉，4月下旬渐暖 |

### 降雨

| 指标 | 数值 |
|------|------|
| 月平均降水量 | 约91–140毫米 |
| 降雨概率 | 约38%–55%/天（大约一半的日子有雨） |
| 预计降雨天数 | 约12–17天/月 |
| 4月中旬特别提示 | 杭州春雨频繁，4月15日前后有降雨可能性 |

### 湿度

- 4月杭州相对湿度较高，约在**70%–85%**之间
- 阴天时体感温度会比实际气温低2–3°C

## 👔 穿着建议（洋葱式穿搭）

### 核心原则：多层叠穿，随时增减

| 时段 | 建议穿着 |
|------|---------|
| **白天晴天** | 长袖T恤/薄衬衫 + 薄外套（夹克/风衣） |
| **白天阴雨** | 长袖T恤 + 薄款毛衣/卫衣 + 防风外套 |
| **早晚（7:00前/18:00后）** | 薄外套必备，怕冷可加薄羽绒内胆或抓绒 |
| **骑行/步行运动时** | 薄长袖+薄外套即可，运动出汗后及时减衣，避免感冒 |
| **4月下旬（如延期出行）** | 气温进一步升高，可备短袖+薄外套组合 |

### 建议携带清单

- ✅ **雨伞或折叠雨衣**（必带！雨天骑行必备）
- ✅ **防水鞋或耐脏运动鞋**（雨天地面湿滑，避免凉鞋/拖鞋）
- ✅ **薄外套/风衣**（1–2件，早晚+阴天必备）
- ✅ **薄款保暖层**（抓绒或薄羽绒内胆，防突然降温）
- ✅ **长袖T恤/衬衫**（2–3件，方便替换）
- ✅ **帽子/墨镜**（晴天防晒，西湖边阳光充足）
- ✅ **便携纸巾/湿巾**（雨天/运动后使用）

## 🌧️ 雨天出行提示

| 场景 | 建议 |
|------|------|
| **骑行** | 小雨可骑（戴帽子+穿防风外套），大雨建议改乘地铁/公交 |
| **步行** | 雨伞必备，注意地面湿滑（青石板路较滑） |
| **景点选择** | 雨天适合参观室内景点：灵隐寺、永福寺、虎跑（涵碧楼等） |
| **交通** | 雨天优先地铁，避开打车/公交高峰拥堵 |
| **装备** | 建议带手机防水袋、相机防雨罩 |

## ☀️ 晴天出行提示

| 时段 | 建议 |
|------|------|
| **上午（9:00–11:00）** | 光线好，适合拍照，游客相对较少 |
| **中午（11:00–14:00）** | 阳光最强，注意防晒，适量补水 |
| **下午（14:00–17:00）** | 气温较高，骑行可能较热，注意休息补水 |
| **傍晚（17:00–19:00）** | 光线柔和，适合西湖边散步赏景 |
