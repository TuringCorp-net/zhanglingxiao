## 二、行前打包清单

> 📅 **基于4月15日杭州气候**：气温11–22°C，春雨旺季，降雨概率38%–55%，早晚温差大

---

### 📋 证件类

- [ ] **身份证**（2人）
- [ ] **优惠证件**（如学生证、老年证、医护人员证件等，现役军人/消防员免票政策）
- [ ] **预约凭证截图**（灵隐飞来峰预约码，保存至手机相册）
- [ ] **健康码/行程码**（备用，以备不时之需）

---

### 👔 衣物类

#### 上装
- [ ] **长袖T恤/薄衬衫** × 2件（方便替换）
- [ ] **薄款抓绒/卫衣** × 1件（保暖层，阴天/早晚必备）
- [ ] **防风夹克/风衣** × 1件（防护层，骑行时挡风）

#### 下装
- [ ] **长裤/牛仔裤** × 2条（避免短裤/裙子，早晚凉且蚊虫多）
- [ ] **备用内裤/袜子** × 2套

#### 鞋袜
- [ ] **防水运动鞋/休闲鞋** × 1双（推荐，防滑防雨）
- [ ] **轻便拖鞋/凉鞋**（备用，住宿使用）

---

### 📱 电子设备类

- [ ] **手机** × 2台（充满电）
- [ ] **充电宝** × 1–2个（建议10000mAh以上，户外一天必备）
- [ ] **数据线/充电线** × 2条（Type-C/Lighting各备）
- [ ] **耳机**（西湖边漫步时使用）
- [ ] **相机**（如有，春季花草拍照效果好）

---

### 🌧️ 雨具类

- [ ] **折叠雨伞** × 2把（晴雨两用，推荐双人双伞）
- [ ] **折叠雨衣** × 1件（骑行时比雨伞更方便）
- [ ] **手机防水袋** × 1个（雨天保护手机）
- [ ] **相机防雨罩**（如有相机）

---

### 💊 药品类

- [ ] **创可贴** × 数片（青石板路走路多，防脚磨）
- [ ] **肠胃药**（旅行肠胃不适备用，如藿香正气水/黄连素）
- [ ] **感冒药**（春季温差大，早晚易着凉）
- [ ] **防蚊液**（春季蚊虫开始活跃，茅家埠等湿地区域必备）
- [ ] **风油精/清凉油**（提神醒脑，晕车也可使用）

---

### 🧴 洗护日用类

- [ ] **防晒霜**（SPF30+，西湖边阳光充足需防晒）
- [ ] **墨镜/太阳镜**（晴天护眼）
- [ ] **遮阳帽**（防晒+拍照道具）
- [ ] **纸巾/湿巾**（户外使用，打包/饮食/运动后清洁）
- [ ] **便携洗漱包**（小容量旅行装）

---

### 🍞 饮食补给类（可选）

- [ ] **小零食/能量棒**（景区徒步补充体力）
- [ ] **矿泉水 × 2瓶**（或到景区购买）
- [ ] **空水壶**（部分农家乐/茶楼可续水）

---

### 🎒 背包类

- [ ] **双肩包/单肩包**（建议双肩包，骑行时更舒适）
- [ ] **收纳袋/保鲜袋**（装湿衣物/垃圾）
- [ ] **折叠购物袋**（逛街购物使用）

## 三、现场执行核对清单

> ✅ **出发前一晚/当天早上，逐项打勾确认**

### 🎫 凭证与预约确认

- [ ] 灵隐飞来峰预约成功（"西湖旅游"小程序查看预约记录）
- [ ] 预约码/二维码截图保存到手机相册（无网时备用）
- [ ] 虎跑公园/植物园电子票已购（如通过美团购买，确认已收到电子票）
- [ ] 餐饮预订凭证（如有电话预订，确认预订信息）

### 🗺️ 路线与地图确认

- [ ] **离线地图下载**：提前下载高德/百度地图杭州离线包（避免信号不好时无法导航）
- [ ] 今日行程路线已规划（参考阶段四C线）
  - 上午：灵隐飞来峰 → 虎跑公园
  - 午餐：梅家坞农家乐
  - 下午：茅家埠 → 柳浪闻莺 → 西湖边骑行
  - 晚餐：河坊街
- [ ] 地铁/骑行路线已确认（龙翔桥→凤起路→灵隐）
- [ ] 农家乐/餐厅位置已标记（丰溢茶楼/外婆家等）

### 💰 支付与财务确认

- [ ] 支付宝/微信钱包已充值或绑定银行卡（杭州全场景支持）
- [ ] 现金少量备款（50–100元，用于小额摊位/备用）
- [ ] 杭州地铁一日票已购（如计划乘地铁≥3次，15元/人/天）
- [ ] 共享单车App已登录（美团/哈啰/青桔，任选一个即可）
- [ ] 公共自行车账号（如需，叮嗒出行App开通）

### 🌤️ 天气与装备确认

- [ ] 出发前日查天气预报（关注是否下雨）
- [ ] 雨具已装包（伞/雨衣）
- [ ] 衣服按洋葱式穿搭：内层长袖 + 保暖层 + 防风外套
- [ ] 防水鞋已穿/已装包

### 📱 手机状态确认

- [ ] 手机电量100%（或带好充电宝）
- [ ] 充电宝已充满
- [ ] 闹钟已设（建议7:00前起床，留足出行准备时间）
- [ ] 重要联系人信息备存

### 🎒 出发前最后确认

- [ ] 房门/窗户关好
- [ ] 行李/背包无遗漏
- [ ] 退房（如需）
- [ ] 告知家人朋友行程（安全告知）
