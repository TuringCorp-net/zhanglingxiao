# Google Docs 写作文件夹

## 用途
这个文件夹专门用于与黎叔进行 Google Docs 写作协作。

## 工作流程
1. 黎叔提出写作需求（如：帮我写一封邮件/报告/文章）
2. 我（虾康康）根据需求创建 Google Docs 文档
3. 文档链接发送给黎叔，黎叔在 Google Docs 网页编辑
4. 如需后续修改，黎叔告知文档链接或文档标题，我继续编辑

## 文档命名规范
`{YYYYMMDD}-{类型}-{主题}.md`

示例：
- `20260329-邮件-感谢信.md`
- `20260329-报告-项目总结.md`
- `20260329-文章-AI助手使用心得.md`

## 注意
- 本地 `.md` 文件是辅助记录，真实文档在 Google Docs 云端
- 创建文档后，将 Google Docs 链接记录在对应的 `.md` 文件里
