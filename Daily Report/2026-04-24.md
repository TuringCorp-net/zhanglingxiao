## 成长积累
- 深入理解了 Cloudflare AI Gateway 的 BYOK（Bring Your Own Key）认证模式：
  - BK token 放在 `cf-aig-authorization` header 里
  - 上游 API Key（如 DeepSeek）由 CF Gateway 代管，不需要客户端发送
  - `authHeader: true` 会导致客户端尝试自己发送 Authorization header，与 BYOK 模式冲突
- 理解了自定义 provider 配置中的 `authHeader` vs `headers` 的区别：`authHeader` 控制 apiKey 如何发送，`headers` 是额外的自定义头
