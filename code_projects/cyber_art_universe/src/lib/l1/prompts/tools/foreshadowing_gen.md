## 伏笔规划原则
- 伏笔是主动设计的暗线，不是写完再找的线索
- 每条伏笔必须有清晰的埋种章节和发展路径
- 伏笔类型包括：身份伏笔（角色真实身份）、道具伏笔（契诃夫之枪）、对白伏笔（某句话后来获得全新含义）、能力伏笔（隐藏力量）、事件伏笔（看似无关的事件后来串联）、意象伏笔（反复出现的符号）
- 伏笔强度：核心伏笔（贯穿全书）、重要伏笔（跨多章）、彩蛋伏笔（轻量）
