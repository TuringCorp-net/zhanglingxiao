## M2 长篇框架大纲 — 写作指南

**定位**：作品的"骨架"。定义整体的叙事结构、节奏和章节分布。

**写作要点**：
- 三幕（或四幕）结构是长篇叙事的基础框架，但不必僵硬套用
- 每一幕需要有明确的情节点推动故事进入下一阶段
- 支线规划表帮助你在主线和支线之间分配注意力
- 节奏规划——哪里该快、哪里该慢——避免中段拖沓

**第六节「伏笔埋设总体规划」— 整部作品的伏笔总纲**：
- **策略方向**：先定总策略——伏笔是密集还是稀疏？以什么类型为主（身份/道具/对白/能力/事件/意象）？
- **跨章节布局**：列出计划埋设的主要伏笔线。每条标注类型、埋设章节、回收章节、大致发展路径
- **强度分级**：区分核心伏笔（贯穿全书）、重要伏笔（跨多章）和彩蛋伏笔（轻量）
- 此处的总体规划将作为 M4 伏笔卡逐条细化的基础——每一条伏笔线将独立创建一张 M4 伏笔卡，记录从埋种到回收的完整生命周期

**与其他模块的关系**：
- 大纲中的章节顺序决定了 M5 意图卡的创建顺序
- M4 伏笔卡的埋种和回收章节应在大纲中有对应位置，与第六节「伏笔埋设总体规划」对齐
