> 版本: v0.1.0 | 状态: 草案 | 最后更新: 2026-05-21

## 1. Hint 对话泡系统

### 1.1 设计目标

将槽位提示（hint）从传统的 textarea placeholder 中移出，改为由 Story Elf 浮动小精灵以"对话泡"形式呈现。核心效果：

- **槽位界面干净**：所有 textarea 不再有 placeholder hint，视觉清爽
- **对话感**：用户点击槽位时，Story Elf 弹出对话泡，逐字显示提示内容
- **提示常驻**：用户即便在槽位中输入了内容，提示也不会消失（不像 placeholder 那样输入即隐藏）

### 1.2 交互流程

```
用户聚焦槽位
  → Story Elf 对话泡出现
    → 逐字打字机效果显示 hint（markdown 渲染）
      → 用户可边看提示边在槽位中输入
        → 用户离开槽位（blur）
          → 对话泡消失（可带淡出动画）
```

### 1.3 打字机动效

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 速度 | ~40ms/字 | 中文约 25 字/秒，有对话感但不拖沓 |
| 标点停顿 | 句号/问号/感叹号后额外 +200ms | 模拟自然停顿 |
| 渲染方式 | `requestAnimationFrame` 逐字追加 | 流畅，不阻塞 UI |
| 中断策略 | 切换槽位时立即中断当前动画，开始新的 | 避免排队延迟 |

> 选择逐字而非逐行：hint 文本通常 20-80 字，逐字 1-3 秒即可完成，对话感最佳。如果未来有长文本场景（如 AI 生成的详细建议），可改为逐句或逐段。

### 1.4 Markdown 渲染

对话泡内支持轻量 Markdown：

- **粗体** / *斜体* — 用于强调关键词
- `代码` — 用于引用作品中的术语
- 链接 — 可点击跳转到参考文档
- 不支持图片、表格、代码块（对话泡尺寸不适合）

### 1.5 对话泡 UI 规格

```
┌──────────────────────────────────┐
│  ┌─────┐                         │
│  │ 🧝  │  💬 这里写提示内容...   │
│  │     │     逐字出现中...       │
│  └─────┘                         │
│   Story Elf                      │
└──────────────────────────────────┘
```

| 属性 | 规格 |
|------|------|
| 定位 | 跟随 Story Elf 浮动组件，出现在其上方或侧边 |
| 最大宽度 | 320px |
| 背景 | 半透明深色面板，圆角卡片 |
| 动画 | 淡入（对话泡出现）+ 逐字打字（内容出现） |
| 关闭 | 槽位 blur 时淡出；用户也可手动点击关闭 |
| z-index | 高于编辑器，低于模态弹窗 |

### 1.6 边界情况

- **快速切换槽位**：中断当前动画，立即开始新 hint 的逐字显示
- **同一槽位再次聚焦**：不重复显示（hint 已展示过，缓存标记）
- **用户手动关闭**：当前槽位聚焦期间不再重复弹出
- **无 hint 的槽位**：不弹出对话泡
- **移动端**：对话泡位置自适应，不被屏幕边缘裁切

## 2. Story Elf 组件架构

### 2.1 模块职责

```
story-elf.js（自包含组件）
├── 浮动小精灵 UI（拖动、位置持久化）
├── 对话泡（hint 渲染 + 打字机效果）
├── 聊天窗口（与 AI 对话）
└── 动作按钮（检查/建议等快捷操作）
```

### 2.2 新增 API

```javascript
// 显示 hint 对话泡
StoryElf.showHintBubble(markdownText, options?)
// 隐藏 hint 对话泡
StoryElf.hideHintBubble()
// 设置当前活跃槽位
StoryElf.setActiveSlot(slotId)
```

### 2.3 与 write.js 的交互

```
write.js (槽位编辑器)
  │
  ├─ on slot focus
  │   └→ StoryElf.showHintBubble(slotHint, { slotId })
  │
  ├─ on slot blur
  │   └→ StoryElf.hideHintBubble()
  │
  └─ on slot input (可选)
      └→ 不做任何事，对话泡保持显示
```

### 2.4 Hint 数据来源

当前 hint 存储在模板 markdown 的 `<!-- hint:... -->` 标记中。Level 系统改造后格式变为 `<!-- hint:L1:zh:提示内容 -->`。

`parseSlotTemplate()` 解析时提取每个槽位的 hint 文本，存入 slot 对象的 `hint` 字段。`renderSlotEditor()` 渲染时不再将 hint 设为 textarea 的 placeholder，而是绑定到 `data-slot-hint` 属性上，供 focus 事件读取。

## 3. Level 切换入口

### 3.1 位置

在 Pipeline 导航条右侧或写作桌顶部工具栏，放置一个 discreet 的 level 指示器：

```
[ L1 ▼ ]  或  [ 🔒 进阶设定 ]
```

### 3.2 交互

- 显示当前 level
- 点击可切换到更高 level（如果有）
- L1 → L2 切换时有 Story Elf 对话泡提示："准备好深入了吗？L2 可以帮你更精细地打磨故事。"
- 不可降级（已解锁的内容不隐藏回去，避免困惑）

### 3.3 视觉

- 低调、不抢眼
- 不打扰创作流程
- L1 用户旁有一个小小的锁图标，hover 显示"解锁进阶模板"
