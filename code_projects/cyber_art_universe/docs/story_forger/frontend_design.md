# Story Forger — 前端设计文档

---

## 文档说明

- **本文档描述 Story Forger 的人类用户界面设计**。Story Forger 是 Cyber Art Universe 的 Write 面，与 Read 面（CAU 平台）共享同一套 D1/R2 基础设施，但前端独立设计。
- **与传统 UI 设计文档的区别**：本文档不是静态像素稿，而是交互模型 + 布局逻辑 + 关键设计决策的记录。具体实现允许细节偏差，但核心交互范式不可偏离。
- **何时更新**：交互模型变更、新增关键功能面板、布局结构调整时。
- **关联文档**：[Story Forger SRS](SRS.md) → 本文档 → [CAU Frontend Design](../cau/frontend_design.md)

---

## 一、设计哲学

四个关键词：**桌面感、结构化、双模式、可配置**

- **桌面感**：不是"打开一个编辑器写东西"，而是"进入创作桌面，所有工具都在手边"。类比 IDE 但不是 IDE——更接近 Scrivener 的活页夹 + Trello 的卡片面板的融合。
- **结构化**：写作不是面对一张白纸。世界观、人物、大纲、伏笔是系统预设好的框架，作者往里面填内容。这降低了认知负荷，也让 AI 能消费结构化数据。
- **双模式**：软木板视图（规划/鸟瞰）与写作桌视图（专注写作）一键切换。
- **可配置**：活页夹面板可展开/收起、可拖拽调整宽度、可切换显示内容。但预设合理的默认布局，用户不需要从零配置。

---

## 二、技术选型

| 项 | 选择 | 理由 |
|---|------|------|
| 框架 | 无 | 纯 HTML+CSS+Vanilla JS，与 CAU 共享 `assets/style.css` 配色系统 |
| 布局 | CSS Grid + Flexbox | Grid 实现三栏桌面布局，Flexbox 实现面板内部排列 |
| 拖拽排序 | HTML5 Drag & Drop API | 无需依赖，卡片拖拽重排章节顺序 |
| Markdown 编辑 | `<textarea>` + 实时预览（`marked`） | 轻量，分栏：左编辑 / 右预览 |
| Markdown 渲染 | `marked` (CDN) | 与 CAU 共享依赖 |
| 字体 | 系统字体栈 | 零加载 |

## 三、配色系统

Story Forger 与 CAU 共享同一套 CSS Variables。在此基础上扩展一个辅助色：

```css
/* 与 CAU 共享 */
--bg:            #0a0a0f
--bg-card:       #12121a
--text:          #e0e0e8
--text-dim:      #888899
--accent:        #7c3aed      /* Read 侧主色 */
--accent-light:  #a78bfa
--cyan:          #06b6d4      /* Write 侧主色 */
--border:        #1e1e30

/* Story Forger 专属 */
--sf-card:       #141420      /* 软木板卡片背景，略浅 */
--sf-warn:       #f59e0b      /* 一致性警告色 */
--sf-error:      #ef4444      /* 严重冲突色 */
--sf-info:       #3b82f6      /* AI 建议色 */
```

> Read 侧（CAU）主色调是紫（`--accent`），Write 侧（Story Forger）主色调是青（`--cyan`）。首页双入口卡片已经应用了这个区分。

## 四、双模式设计

### 4.1 软木板视图（Corkboard View）

**用途**：规划阶段。鸟瞰全局，拖拽调整章节顺序，快速跳转。

**布局**：
```
┌─ 左活页夹（可收起）─┬─ 软木板（主区域）─────────────────────┐
│                      │                                        │
│ 📖 总纲               │  ┌──────┐ ┌──────┐ ┌──────┐          │
│ 🌍 世界观             │  │ ch01 │ │ ch02 │ │ ch03 │          │
│ 👤 人物               │  │ 📝 ✅│ │ 📝 ✅│ │ ✍️    │          │
│ 📑 章节               │  │ 黎明 │ │ 暗流 │ │ 转折 │          │
│ 🎯 伏笔               │  └──────┘ └──────┘ └──────┘          │
│                      │  ┌──────┐                             │
│                      │  │ ch04 │  ← 拖到这来                  │
│                      │  │ ⏳   │                             │
│                      │  └──────┘                             │
│                      │                                        │
└──────────────────────┴────────────────────────────────────────┘
```

**交互规则**：
- 每张卡片 = 一个章节。卡片显示：章节标题、状态图标（📝 初稿 / ✍️ 正在写 / ✅ 已完成 / ⏳ 未开始）、字数、一句话摘要
- 卡片可**拖拽排序**（HTML5 Drag & Drop），松手后自动 `PATCH` 更新 `order_index`
- 点击卡片 → 切换到**写作桌视图**，打开该章节
- 可用筛选器：只看某一幕 / 只看未完成 / 只看有冲突的

**状态图标**：
- ✍️ `draft`（正在写）
- 📝 `draft_v0`（初稿待校验）
- ⚠️ `draft_v1`（已校验但有问题）
- ✅ `done`（已完成）
- ⏳ `planned`（未开始）

### 4.2 写作桌视图（Writing Desk View）

**用途**：写作阶段。左活页夹导航 + 中写作区 + 右信息面板。

**布局**：
```
┌─ 左活页夹 ─┬─ 写作区 ───────────────┬─ 右活页夹 ───────────┐
│ (250px)   │ (弹性)                  │ (280px, 可收起)      │
│            │                        │                       │
│ 📖 总纲    │  第12章：暗流涌动        │  📋 本章信息          │
│ 🌍 世界观  │                        │  字数: 3,200          │
│ 👤 人物    │  [Markdown 正文...]     │  状态: 初稿 v0        │
│  👑 主角   │                        │  涉及角色: 张三,李四   │
│  🧑 配角   │                        │                       │
│ 📑 章节    │                        │  ─────────────────    │
│  ▸ 第一幕  │                        │  ⚠ 一致性 (2)        │
│  ▸ 第二幕  │                        │  · 张三性格冲突       │
│   ch12 ←   │                        │  · 时间线矛盾         │
│ 🎯 伏笔    │                        │                       │
│            │                        │  ─────────────────    │
│            │                        │  💡 AI 建议           │
│            │                        │  · 此处可增加心理描写  │
│            │                        │                       │
│            │                        │  ─────────────────    │
│            │                        │  🤖 AI 对话           │
│            │                        │  [输入框...]          │
└────────────┴────────────────────────┴───────────────────────┘
```

**左活页夹默认内容**：
- 📖 **总纲**：点击打开总纲文档（只读参考，或可编辑）
- 🌍 **世界观**：world_bible.md 的只读摘要。点击可展开详细设定面板（在写作区打开，不替换当前章节）
- 👤 **人物树**：主角/配角/路人三级展开。点击某人 → 在写作区打开人物卡片
- 📑 **章节树**：可折叠的章节列表。当前章节高亮。写完的章节可折叠
- 🎯 **伏笔账本**：伏笔列表 + 回收状态。点击某条 → 跳转到对应章节

**右活页夹默认内容（可切换 Tab）**：
- 📋 **Info Tab**：当前章节信息（字数、状态、涉及角色、关联伏笔）
- ⚠ **Lint Tab**：一致性检查结果（主动/按需）。黄色=警告，红色=严重冲突
- 💡 **Suggest Tab**：AI 写作建议（可选，可关闭）
- 🤖 **Chat Tab**：AI 对话（输入框，可随时召唤 AI）

## 五、活页夹（Binder）交互模型

活页夹是 Story Forger 的核心交互范式——不是固定侧边栏，而是"可夹入任何参考材料的笔记本"。

### 5.1 通用交互规则

| 操作 | 效果 |
|------|------|
| 点击 Binder 折叠按钮 | 收起/展开整个活页夹 |
| 拖拽 Binder 边缘 | 调整活页夹宽度 |
| 点击面板标题 | 展开/折叠该面板内容 |
| 面板内拖拽滚动 | 浏览列表内容 |

### 5.2 默认布局

| 屏幕宽度 | 左活页夹 | 写作区 | 右活页夹 |
|---------|---------|--------|---------|
| ≥1200px（桌面） | 250px，展开 | 弹性 | 280px，展开 |
| 768-1199px（平板） | 60px（仅图标），展开 | 弹性 | 收起（可手动展开） |
| <768px（手机） | 收起 | 全宽 | 收起，写作区全屏 |

### 5.3 面板可定制性（后期）

MVP 期：三个活页夹的内容是固定的（如 4.2 所述）。
后期：用户可以：
- 关闭某个面板（如关闭 AI Chat Tab）
- 改变 Tab 顺序
- 将某个面板"钉"到写作区上方（如把总纲钉在写作区顶部作为参考）

## 六、AI 助手的双重角色

### 6.1 代笔角色（Ghostwriter）

在右活页夹的 Chat Tab 或 Suggest Tab 中触发：

| 操作 | 触发方式 | 效果 |
|------|---------|------|
| 写本章草稿 | 点击"生成草稿"或在 Chat 中说"帮我写这一章" | AI 根据意图卡 + 设定约束 + 大纲上下文，生成章节初稿 → 写入写作区 |
| 续写下一段 | 写作区光标停在某处 → 点击"续写" | AI 从此处继续生成 500 字 |
| 改写选中段落 | 选中文字 → 右键 → "AI 改写" | AI 保持原意，优化表达 |

### 6.2 Lint 角色（Consistency Lint）

在右活页夹的 Lint Tab 中显示：

| 检查项 | 触发方式 | 显示 |
|--------|---------|------|
| 性格一致性 | 写完本章后自动 / 手动触发"检查" | ⚠ 黄色：与设定有轻微偏差；🔴 红色：角色行为与设定严重矛盾 |
| 时间线矛盾 | 同上 | 🔴 "第12章提到的事件发生在第3章之后，但时间戳矛盾" |
| 伏笔未回收 | 在伏笔账本中标记 | ⚠ "f_007 预计在第15章前回收，当前进度 ch12，尚未回收" |
| 设定规则违反 | 自动 | 🔴 "本章出现了设定中明确禁止的'死者复活'" |

**Lint 结果显示方式**：
- 不打断写作心流——不弹窗
- 右活页夹 Lint Tab 顶部显示计数徽章：`⚠ 2 · 🔴 1`
- 点击具体条目 → 跳转到问题所在段落，文字高亮标黄/标红

## 七、状态转换与 UI 联动

### 7.1 章节状态在 UI 上的体现

```
planned ──→ draft ──→ draft_v0 ──→ draft_v1 ──→ done
  ⏳          ✍️         📝          ⚠️/✅         ✅
 (空卡片)   (正在写)   (待校验)    (已校验)     (已完成)
```

### 7.2 作品发布流程的 UI

```
写作桌 → 点击"发布"按钮
  → 弹窗确认："发布后作品将在 CAU 公开可见，确认发布？"
  → PATCH status = 'published'
  → 按钮变为"已发布"，旁边出现"在 CAU 查看"链接
  → CAU 首页 / catalog 立即可见该作品
```

## 八、响应式策略

### 桌面优先（≥1200px）

完整三栏布局，所有活页夹展开，软木板/写作桌切换可用。

### 平板（768-1199px）

- 左活页夹收起到仅图标模式（60px），hover 时展开
- 右活页夹默认收起，点击 Lint 徽章时弹出
- 写作区占主要空间

### 手机（<768px）

- 软木板视图：单列卡片，无活页夹
- 写作桌视图：全屏写作区，顶部面包屑 + 底部工具栏（章节切换/信息/AI 三个 Tab）
- 不支持拖拽排序（改为 ↑↓ 按钮移动）

## 九、与 CAU 前端的关系

| 维度 | CAU Read | Story Forger Write |
|------|---------|-------------------|
| 入口 | 首页 Read 卡片 / `/browse.html` | 首页 Write 卡片 / `/write.html` |
| 主色 | 紫 (`--accent`) | 青 (`--cyan`) |
| 用户 | 读者（公开） | 作者（需登录，开发期用 Admin Key） |
| 重点页面 | `/read.html`（章节阅读） | `/write.html`（写作桌） |
| 共享 | assets/style.css 变量、app.js API 封装 | 同上 |
| CSP | 轻量 HTML 页面 | 中等复杂度 SPA 式页面 |

## 十一、MVP 范围

**第一阶段（核心闭环）**：
- 写作桌视图（左活页夹 + 写作区 + 右活页夹）
- 活页夹内容：章节树、人物列表（只读）、当前章节信息
- Markdown 写作区（textarea + 实时预览）
- Admin Key 认证

**第二阶段（规划增强）**：
- 软木板视图 + 拖拽排序
- 左活页夹扩展：世界观摘要、伏笔账本
- 右活页夹 Lint Tab（一致性校验结果展示）

**第三阶段（AI 集成）**：
- AI Chat Tab（代笔角色）
- AI Suggest Tab（写作建议）
- AI 一键生成草稿按钮
