# Story Forger — 前端设计文档

---

## 文档说明

- **本文档描述 Story Forger 的人类用户界面设计**。Story Forger 是 Cyber Art Universe 的 Write 面，与 Read 面（CAU 平台）共享同一套 D1/R2 基础设施，但前端独立设计。
- **与传统 UI 设计文档的区别**：本文档不是静态像素稿，而是交互模型 + 布局逻辑 + 关键设计决策的记录。具体实现允许细节偏差，但核心交互范式不可偏离。
- **何时更新**：交互模型变更、新增关键功能面板、布局结构调整时。
- **关联文档**：[Story Forger SRS](SRS.md) → 本文档 → [CAU Frontend Design](../cau/frontend_design.md)

---

## 一、设计哲学

四个关键词：**桌面感、结构化、统一界面、可配置**

- **桌面感**：不是"打开一个编辑器写东西"，而是"进入创作桌面，所有工具都在手边"。
- **结构化**：写作不是面对一张白纸。世界观、长篇框架、人物卡、伏笔账本是系统预设好的模板，作者往里面填内容。降低了认知负荷，也让 AI 能消费结构化数据。
- **统一界面**：不区分"规划模式"和"写作模式"。左活页夹（五大面板：总纲/世界观/人物/章节/伏笔）+ 中写作区 + 右 AI 辅助面板，一个界面完成所有操作。
- **可配置**：活页夹面板可展开/收起、可拖拽调整宽度。但预设合理的默认布局，用户不需要从零配置。

## 二、技术选型

| 项 | 选择 | 理由 |
|---|------|------|
| 框架 | 无 | 纯 HTML+CSS+Vanilla JS，与 CAU 共享 `assets/style.css` 配色系统 |
| 布局 | CSS Grid + Flexbox | Grid 实现三栏桌面布局，Flexbox 实现面板内部排列 |
| 拖拽排序 | HTML5 Drag & Drop API | 无需依赖，卡片拖拽重排章节顺序 |
| Markdown 编辑 | `<textarea>` + 实时预览（`marked`） | 轻量，分栏：左编辑 / 右预览 |
| Markdown 渲染 | `marked` (CDN) | 与 CAU 共享依赖 |
| 字体 | 系统字体栈 | 零加载 |

/* Story Forger 专属 */
--sf-card:       #141420      /* 软木板卡片背景，略浅 */

## 四、写作引导流程（Pipeline Guide）

### 4.1 设计意图

长篇创作的最大障碍不是"不会写"，而是"不知道该从哪开始"。Story Forger 的六大模块有明确的先后逻辑，将这条流水线可视化为一个**始终可见的引导条**，让新手作者像做交互式配置一样完成创作。

### 4.2 引导条设计

引导条位于工具栏下方，始终可见（软木板和写作桌模式都显示）：

```
┌──────────────────────────────────────────────────────────────────┐
│  创作引导：                                                       │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐         │
│  │ ✓ 世界观  │→│ ✓ 主线   │→│ ● 人物   │→│ ○ 伏笔   │→  ...   │
│  │   M1     │  │   M2     │  │   M3     │  │   M4     │         │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘         │
│   已完成         已完成         当前步骤      待开始              │
└──────────────────────────────────────────────────────────────────┘
```

### 4.3 交互规则

| 规则 | 说明 |
|------|------|
| 始终可见 | 引导条是页面级的持久元素，始终显示在工具栏下方 |
| 状态驱动 | 每个步骤根据对应 R2 资产自动判定状态（已完成 ✓ / 进行中 ● / 待开始 ○） |
| 点击跳转 | 点击任意步骤 → 跳转到对应模块面板（如在写作桌模式则展开对应左活页夹面板） |
| 建议顺序 | 新作品默认高亮 M1 为"建议从这里开始"，已完成步骤不强制顺序 |
| 可跳过 | 有经验的作者可以跳过顺序，直接点击任意模块 |

### 4.4 步骤与模块的映射

| 步骤 | 标签 | 状态判定依据 | 点击行为 |
|------|------|------------|---------|
| M1 | 🌍 世界观 | `world_bible.md` 存在且有任何实质填充内容 | 展开左活页夹世界观面板 |
| M2 | 📖 主线剧情 | `outline.md` 存在或有 sections 记录 | 展开左活页夹总纲面板 |
| M3 | 👤 人物卡 | entities 表中有 character 类型的记录 | 展开左活页夹人物树面板 |
| M4 | 🎯 伏笔账本 | `foreshadowing.md` 存在且非模板 | 展开伏笔账本面板 |
| M5 | 📋 章节蓝图 | 存在至少 1 个章节的意图卡 | 切换到软木板视图 |
| M6 | ✍️ 逐章编写 | 存在至少 1 个章节正文 | 展开章节树面板 |

### 4.5 响应式适配

- **桌面（≥1200px）**：完整 6 步水平排列
- **平板（768-1199px）**：6 步水平排列，步骤标签缩短（如"M1 世界观"→"世界观"）
- **手机（<768px）**：改为可左右滑动的横向滚动条，当前步骤自动居中

## 五、写作桌布局（唯一界面）

Story Forger 不再区分"规划模式"和"写作模式"。统一的三栏写作桌完成所有操作。

**布局**：
```
┌─ 左活页夹 ─┬─ 写作区 ───────────────┬─ 右活页夹 ───────────┐
│ (250px)   │ (弹性)                  │ (280px, 可收起)      │
│            │                        │                       │
│ 📖 总纲    │  编辑器可编辑：          │  📋 信息 Tab          │
│ 🌍 世界观  │  · 章节正文             │  ⚠ 检查 Tab          │
│ 👤 人物树  │  · 世界观 Markdown      │  💡 建议 Tab          │
│ 📑 章节树  │  · 长篇框架             │  🤖 对话 Tab          │
│ 🎯 伏笔    │  · 人物卡               │                       │
│            │                        │                       │
│ 章节筛选： │  [Markdown 编辑/预览]   │                       │
│ [全部]     │                        │                       │
│ [写作中]   │                        │                       │
│ [已完成]   │                        │                       │
└────────────┴────────────────────────┴───────────────────────┘
```

**左活页夹面板**：

| 面板 | 内容 | 交互 |
|------|------|------|
| 📖 总纲 | 作品元信息 + 长篇框架模板 | 点击展开，AI 生成/手动编辑 |
| 🌍 世界观 | Setting Bible 模板（中英双语） | AI 生成或手动填写 |
| 👤 人物树 | 实体列表（角色/地点/道具） | 点击角色 → 写作区打开人物卡 |
| 📑 章节树 | 可拖拽排序的章节列表 + 状态筛选 | 拖拽重排，点击切换章节，筛选按钮 |
| 🎯 伏笔账本 | 伏笔规划模板 | AI 规划或手动填写 |

**章节树增强**（从软木板迁移）：
- **拖拽排序**：HTML5 Drag & Drop，松手后自动更新 `order_index`
- **状态筛选**：章节数 >3 时自动显示 [全部 / ✍️ 写作中 / ✅ 已完成] 按钮
- **状态图标**：✍️ draft / 📝 draft_v0 / ✅ done / ⏳ planned

**右活页夹 Tab**：
- 📋 **Info**：当前章节信息（字数、版本、AI 标注）
- ⚠ **Lint**：一致性检查结果
- 💡 **Suggest**：AI 写作建议
- 🤖 **Chat**：AI 对话

## 六、工具条与语言切换

工具条是工作区选择器 + 模式切换 + 语言控制 + 操作按钮的组合条，始终可见。

### 6.1 语言选择器

```
🌐 [中文 ▾]   [✓] 双语生成
```

- **语言下拉**：切换当前写作/显示语言。zh（中文）/ en（English），后续扩展 ja/ko/fr
- **双语生成复选框**：默认勾选。勾选时，AI 生成操作同时产出 zh + en 两个版本。取消则仅生成当前语言
- 语言偏好存储到 `localStorage`，跨会话持久化
- 切换语言时自动刷新当前面板内容（世界观、章节等按新语言加载）

### 6.2 成本说明

- 双语生成：AI 调用 ×2，成本翻倍。两个调用并行发出，不增加等待时间
- 有经验的作者可以取消勾选，快速迭代时节省成本
- 定型后再勾选双语，生成完整多语言版本

## 七、活页夹（Binder）交互模型

活页夹是 Story Forger 的核心交互范式——不是固定侧边栏，而是"可夹入任何参考材料的笔记本"。

### 7.1 通用交互规则

| 操作 | 效果 |
|------|------|
| 点击 Binder 折叠按钮 | 收起/展开整个活页夹 |
| 拖拽 Binder 边缘 | 调整活页夹宽度 |
| 点击面板标题 | 展开/折叠该面板内容 |
| 面板内拖拽滚动 | 浏览列表内容 |

### 7.2 默认布局

| 屏幕宽度 | 左活页夹 | 写作区 | 右活页夹 |
|---------|---------|--------|---------|
| ≥1200px（桌面） | 250px，展开 | 弹性 | 280px，展开 |
| 768-1199px（平板） | 60px（仅图标），展开 | 弹性 | 收起（可手动展开） |
| <768px（手机） | 收起 | 全宽 | 收起，写作区全屏 |

### 7.3 面板可定制性（后期）

MVP 期：三个活页夹的内容是固定的（如 4.2 所述）。
后期：用户可以：
- 关闭某个面板（如关闭 AI Chat Tab）
- 改变 Tab 顺序
- 将某个面板"钉"到写作区上方（如把总纲钉在写作区顶部作为参考）

## 七、AI 助手的双重角色

### 7.1 代笔角色（Ghostwriter）

在右活页夹的 Chat Tab 或 Suggest Tab 中触发：

| 操作 | 触发方式 | 效果 |
|------|---------|------|
| 写本章草稿 | 点击"生成草稿"或在 Chat 中说"帮我写这一章" | AI 根据意图卡 + 设定约束 + 大纲上下文，生成章节初稿 → 写入写作区 |
| 续写下一段 | 写作区光标停在某处 → 点击"续写" | AI 从此处继续生成 500 字 |
| 改写选中段落 | 选中文字 → 右键 → "AI 改写" | AI 保持原意，优化表达 |

### 7.2 Lint 角色（Consistency Lint）

在右活页夹的 Lint Tab 中显示：

| 检查项 | 触发方式 | 显示 |
|--------|---------|------|
| 性格一致性 | 写完本章后自动 / 手动触发"检查" | ⚠ 黄色：与设定有轻微偏差；🔴 红色：角色行为与设定严重矛盾 |
| 时间线矛盾 | 同上 | 🔴 "第12章提到的事件发生在第3章之后，但时间戳矛盾" |
| 伏笔未回收 | 在伏笔账本中标记 | ⚠ "f_007 预计在第15章前回收，当前进度 ch12，尚未回收" |
| 设定规则违反 | 自动 | 🔴 "本章出现了设定中明确禁止的'死者复活'" |

**Lint 结果显示方式**：
- 不打断写作心流——不弹窗
- 右活页夹 Lint Tab 顶部显示计数徽章：`⚠ 2 · 🔴 1`
- 点击具体条目 → 跳转到问题所在段落，文字高亮标黄/标红

## 八、状态转换与 UI 联动

### 8.1 章节状态在 UI 上的体现

```
planned ──→ draft ──→ draft_v0 ──→ draft_v1 ──→ done
  ⏳          ✍️         📝          ⚠️/✅         ✅
 (空卡片)   (正在写)   (待校验)    (已校验)     (已完成)
```

### 8.2 作品发布流程的 UI

```
写作桌 → 点击"发布"按钮
  → 弹窗确认："发布后作品将在 CAU 公开可见，确认发布？"
  → PATCH status = 'published'
  → 按钮变为"已发布"，旁边出现"在 CAU 查看"链接
  → CAU 首页 / catalog 立即可见该作品
```

## 九、响应式策略

### 桌面优先（≥1200px）

完整三栏布局，所有活页夹展开，软木板/写作桌切换可用。

### 平板（768-1199px）

- 左活页夹收起到仅图标模式（60px），hover 时展开
- 右活页夹默认收起，点击 Lint 徽章时弹出
- 写作区占主要空间

### 手机（<768px）

- 软木板视图：单列卡片，无活页夹
- 写作桌视图：全屏写作区，顶部面包屑 + 底部工具栏（章节切换/信息/AI 三个 Tab）
- 不支持拖拽排序（改为 ↑↓ 按钮移动）

## 十、与 CAU 前端的关系

| 维度 | CAU Read | Story Forger Write |
|------|---------|-------------------|
| 入口 | 首页 Read 卡片 / `/browse.html` | 首页 Write 卡片 / `/write.html` |
| 主色 | 紫 (`--accent`) | 青 (`--cyan`) |
| 用户 | 读者（公开） | 作者（需登录，`Authorization: Bearer` token） |
| 重点页面 | `/read.html`（章节阅读） | `/write.html`（写作桌） |
| 共享 | assets/style.css 变量、app.js API 封装 | 同上 |
| CSP | 轻量 HTML 页面 | 中等复杂度 SPA 式页面 |
