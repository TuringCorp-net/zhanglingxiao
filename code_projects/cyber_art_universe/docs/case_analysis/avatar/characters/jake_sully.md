# 人物卡：Jake Sully（杰克·萨利）

> 本文档以 Story Forger M3 人物卡模板逆向拆解《阿凡达》的主角——Jake Sully。
> Jake 是 Joseph Campbell "英雄之旅"（单一神话）在 21 世纪的科幻呈现。

---

## 一、基本信息

- **姓名**：Jake Sully（杰克·萨利）
- **身份/职业**：前美国海军陆战队一等兵（因伤退役） → 阿凡达驾驶员 → Omaticaya 部落成员 → 魅影骑士（第六代 Toruk Makto）→ Omaticaya 部落领袖
- **年龄**：约 28-30 岁
- **外表特征**：人类形态——双腿瘫痪（轮椅）、健壮的上半身；阿凡达形态——约 3 米高、蓝色皮肤、五根手指（这是区分阿凡达和纳威人的视觉标识——真正的纳威人只有四根手指）
- **在故事中的角色**：第一主角

---

## 二、性格与动机

### 核心性格
直率、勇敢、海军陆战队的本能（"被锤打得够硬"）、对自由有刻入骨髓的渴望

### 内在动机
**自由**——不只是物理的（重新行走），还是存在的（从"军队的工具"变为"选择自己命运的人"）。

Jake 的开场旁白："我梦想飞翔。每次我醒来，我仍在轮椅中。"
"飞翔"在 Jake 的语言中 = 自由——物理的、身份的、灵魂的。

### 外在目标
- **早期（被 Quaritch 操控时）**：获取情报 → 换取恢复双腿的手术
- **中期（在纳威人中学习时）**：通过仪式成为部落的一员
- **晚期（Hometree 被毁后）**：领导纳威人反抗 RDA 的侵略，保护潘多拉

### 恐惧与弱点
- 被困在无用的身体中——这是他的核心创伤
- 在"两个世界之间飘着"——每一边都不完全属于
- 害怕失去 Neytiri——她是他在潘多拉找到的"家"的唯一证明

### 价值观与底线
- 海军陆战队的信条："不落下任何一个兄弟"——这映射到他对纳威人的忠诚："我不会让他们被毁灭"
- 当意识到自己在帮助"坏的一方"时，他有能力改变阵营——这不是背叛，这是"纠正自己"

---

## 三、能力与限制

### 能力/技能
- 海军陆战队战斗训练（武器操作、战术思维、生存技能）
- 经阿凡达身体放大后：纳威人的 4 倍人类力量、攀爬、奔跑、野外生存
- **关键能力：无畏**——Jake 在锤头犀牛面前站住不动的场景——这不是力量，是勇气。这种勇气让 Neytiri 震撼："你有强大的心——没有恐惧——但愚蠢。"
- 快速学习能力（纳威语、骑乘、狩猎——在 3 个月内完成）

### 能力边界
- **双腿瘫痪的人类身体**是最初的牢笼——即使他的意识在阿凡达中自由奔跑，他的"真"身体仍在轮椅上
- **在阿凡达中时，人类身体处于沉睡状态且完全脆弱**——这是 Jake 最大的弱点。Quaritch 通过攻击连接舱来杀死 Jake
- **被双重身份撕裂**：他既不完全是人类，也不完全是纳威人。只有通过意识转移（消除人类身体）才能彻底解决这个矛盾

### 资源与人脉
- Quaritch 的"交易"（腿部手术 = 情报）——早期资源，后被放弃
- Grace 的科学知识——她是 Jake 在"人类世界"中唯一真正的盟友
- Neytiri 的信任和爱情——Jake 在纳威世界中的"签证"
- Toruk（魅影飞龙）——获得所有纳威部族的领导权

---

## 四、关系网络

### 与 Neytiri 的关系
从"猎物"（她救了他） → "学生"（她教他） → "伴侣"（她选择了他） → "被背叛的人"（他暴露为间谍） → "被原谅的人"（他驯服 Toruk 后） → "一起战斗的人"（最终大战） → "终生的伴侣"（意识转移后——"I see you" 第三次，也是最后一次）

这是《阿凡达》的情感脊梁。

### 与其他核心人物的关系
| 人物 | 关系性质 |
|------|---------|
| Grace Augustine | 最初的不信任 → 理解（Grace 发现 Jake "不只是个军人"） → Grace 为他牺牲 |
| Quaritch | 利用与被利用 → 对立 → 殊死决斗。Quaritch 是 Jake 的"如果我没有改变阵营会变成什么样"的镜像 |
| Neytiri | 如上——情感脊梁 |
| Tsu'tey | 单向的敌意（Tsu'tey 对 Jake） → 临终前的接纳——"你是 Omaticaya" |

---

## 五、成长弧线

### 弧线类型
**蜕变型**——从"人类的战争工具"到"纳威部落的精神领袖"——身份的根本转变，不只是角色的成长

### 起点状态
一个双腿瘫痪的退伍军人，住在破烂的公寓里，没有未来。"我的生命不值一提。"

### 关键成长节点

1. **第一次进入阿凡达——"我重新有了腿"**（节拍 3）
   → 物理自由的恢复——Jake 在这个世界中的"第一次自己选择跑向哪里"

2. **Neytiri 救了 Jake + Woodsprites 的"神谕"**（节拍 4-5）
   → 从"被当做外来者准备被杀"到"被 Eywa 选中"——身份的第一次转变

3. **通过 Dream Hunt 成为部落正式成员**（节拍 9）
   → 被纳威人接纳为"自己人"——从此"间谍"的身份不再站得住脚

4. **推土机事件——Jake 第一次以暴力对抗 RDA**（节拍 11）
   → 从"观察者"到"行动者"

5. **Hometree 被毁——Neytiri："你永远不是我们的人"**（节拍 12-13）
   → 最低点——失去一切信任、一切归属

6. **驯服 Toruk——成为第六代魅影骑士**（节拍 17）
   → "不可能的故事"——用神话叙事的方式赢回信任

7. **Eywa 的祷告——Eywa 回应了**（节拍 21）
   → Jake 的"信仰"从体验变成了行动——他激活了 Eywa

8. **意识转移——永久成为纳威人**（节拍 24-25）
   → "是时候把借来的还回去了"——Jake 放弃了人类的身份——这不是逃避人类身份，而是选择了他的"真正的自己"

### 终点状态
- 完全成为纳威人——不仅在外表上，在部落地位上（部落领袖）
- 与 Neytiri 成为终生的伙伴
- 在《阿凡达》结尾时是一个完成循环的弧线——但在续集中发现，"成为领袖"只是新的挑战的开始

## 六、语言与行为特征

### 说话风格
- **日志体**：直白、简洁、有时自嘲——"我是海军陆战队员——被锤打得够硬。"
- **对 Neytiri**：从笨拙（"我不明白——"）到流畅（正式学习纳威语）
- **对 Quaritch**：早期带有军人对上级的尊敬——但逐渐转变为嘲讽
- **战前演说**："天空人说他们可以拿走任何他们想要的东西。但我们将告诉他们——这是我们的土地！"——简洁、直接、海军陆战队式的动员

### 习惯动作
- 在人类身体中：无意识地按摩自己的残腿
- 在阿凡达身体中：用脚趾在地面上蹭——感受泥土、草地、地面——每一次站立都是对轮椅上岁月的对抗

### 外貌细节
- 人类 Jake：手臂强壮（轮椅生活使上半身健壮）、下半身萎缩
- 阿凡达 Jake：五根手指（视觉上区分于真正纳威人）、逐渐变得更"纳威化"——皮肤上的仪式纹路、头发上的串珠
- Jake 的阿凡达外表从"蓝皮肤的美国人"逐渐变成"一个真正的纳威战士"

### 特殊癖好
- **挖泥土**：第一次进入阿凡达时，他用手挖起泥土闻——"这是真的。"
- **记录日志**：即使在被部落接纳后，他仍坚持记录视频日志——这是他"以前的身份"的唯一联系
