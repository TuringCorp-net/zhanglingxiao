# 人物卡：Colonel Miles Quaritch（迈尔斯·夸里奇上校）

> 本文档以 Story Forger M3 人物卡模板逆向拆解《阿凡达》的主要反派——Quaritch 上校。
> Quaritch 被广泛批评为"卡通式反派"——但这种"扁平"在神话叙事中是有功能性的。

---

## 一、基本信息

- **姓名**：Colonel Miles Quaritch（迈尔斯·夸里奇上校）
- **身份/职业**：RDA 安保部队指挥官、前海军陆战队上校
- **年龄**：约 50 岁
- **外表特征**：肌肉型军人、脸上有多处战斗伤痕、光头、"每一条伤疤都是一个故事"
- **在故事中的角色**：主要反派 / Jake 的"黑暗镜像"

---

## 二、性格与动机

### 核心性格
残忍、务实、有魅力（以"硬汉"的方式）、对纳威人有根植于恐惧的仇恨

### 内在动机
**控制**——恐惧潘多拉（对他来说潘多拉是"地狱"），而这种恐惧表现为"必须征服它"的暴力意志

### 外在目标
- 强制纳威人离开 Hometree → 让 RDA 开采地下价值连城的 Unobtanium 矿脉
- 训练 Jake 为内应 → 获取纳威人的防御情报
- 摧毁纳威人的抵抗力量 → "震慑与恐惧"

---

## 三、能力与限制

### 能力/技能
- 顶级军事指挥官——战术部署、战场指挥
- AMP 机甲（大型人形武器平台）的操作——他是 RDA 最好的机甲驾驶员
- 军事心理学——他识别 Jake 的欲望（恢复双腿）并精确地利用它

### 能力边界
- **完全无法理解纳威人的视角**——潘多拉对他来说"就是地狱"
- **没认识到科学的价值**——对他来说 Grace 只是"碍事的科学家"
- **被自己的傲慢杀死**——他从没想过 Neytiri 的弓箭能穿透 AMP 机甲的玻璃

---

## 四、人物设计的叙事功能

Quaritch 是"单一神话"中必要的角色——**"门槛守护者"作为终极大反派**。

为什么 Quaritch 必须"扁平"：
1. 他是殖民逻辑的**纯粹化身**——他不是被"误导的好人"，他是殖民暴力的具象化
2. 在观众的情感坐标上，他提供了一个清晰的"敌人"——Neytiri 射中他是整个电影最令人满足的瞬间
3. 他的存在解放了 Jake 的弧线——Jake 不需要犹豫"Quaritch 也许是对的"

**M3 模板的关键发现**：模板需要能承载"功能型反派"——不是所有角色都需要深度弧线。有些角色之所以成功，是因为他们**没有**弧线。M3 的"弧线类型"字段应增加"功能型（无弧线）"选项。

---

## 五、M3 模板适配度

Quaritch 是 M3 的一个特殊测试案例——他是一个文学上"扁平"但功能上完美的角色。M3 模板不应该强迫每个角色都有"复杂动机"和"成长弧线"。有时候，"一个纯粹的反派"就是正确的叙事选择。这与《魔戒》中的索伦功能相同——索伦也从未露面、没有弧线、没有动机复杂度——他只需要"在那里"作为终极邪恶的存在。
