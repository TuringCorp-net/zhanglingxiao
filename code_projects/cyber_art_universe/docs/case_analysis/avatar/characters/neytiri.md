# 人物卡：Neytiri（妮特丽）

> 本文档以 Story Forger M3 人物卡模板逆向拆解《阿凡达》的女主角——Omaticaya 部落公主 Neytiri。
> Neytiri 不是"需要被拯救的公主"——她是 Jake 的导师、保护者和灵魂的审判者。

---

## 一、基本信息

- **姓名**：Neytiri te Tskaha Mo'at'ite（妮特丽·特·茨卡哈·莫阿特之女）
- **身份/职业**：Omaticaya 部落公主、下一任萨满（Tsahìk）的天然人选、部落最优秀的猎手之一
- **年龄**：约 18-20 纳威年（纳威人寿命 160-180 年，相当于人类约 20-25 岁）
- **外表特征**：典型的纳威女性——约 2.8 米高、蓝色条纹皮肤、生物荧光斑点、四根手指、猫一般的金色大眼睛
- **在故事中的角色**：女主角 / 导师 / Jake 的灵魂伴侣

---

## 二、性格与动机

### 核心性格
骄傲、警觉、凶猛、情感深刻、对 Eywa 有绝对的信仰

### 内在动机
保护她的部落和 Eywa——她是下一任萨满的人选，这意味着她是"聆听 Eywa 的声音并解读它"的人。

### 外在目标
- **早期**：完成对 Jake 的教导——母亲的命令
- **中期**：接受 Jake 作为她的终身伴侣——自愿的选择
- **后期**：原谅 Jake 的背叛并与之一同战斗——选择再次信任他

### 恐惧与弱点
- 对"天空人"的恐惧——她的部落已被 RDA 威胁了多年
- 被 Jake 背叛后的愤怒——不是对"敌人"的愤怒，而是对"她信任过的人"的愤怒——这是更大的伤害
- **失去父亲 Eytukan**——这是她的生命的转折点——从"公主"到"必须领导的人"

### 价值观与底线
- Eywa 的意志高于一切——Woodsprites 落在 Jake 身上时，她放下杀他的箭——不是因为喜欢他，而是因为 Eywa 的意志
- "所有能量都是借来的，有一天必须归还"——这是她教 Jake 的第一课
- 家庭和部落的忠诚——但当 Jake 证明自己是"真的"纳威人（驯服 Toruk）后，她能原谅他

---

## 三、能力与限制

### 能力/技能
- 顶级猎手：弓箭、骑乘（Direhorse、Ikran）、追踪
- Ikran 飞行技术——在空中战斗的能力
- 解读 Eywa 的意志——作为下一任萨满的训练
- 纳威生存技能：植物识别、野外医疗、攀爬
- 教授能力：她能将复杂的纳威文化概念翻译给一个完全无知的外来者

### 能力边界
- 不能直接对抗 RDA 的军事力量——她的弓箭对 AMP 机甲无效
- 她的信仰（Eywa 不偏袒任何一方）限制了她在战斗中的策略——她不相信 Eywa 会在战斗中帮助纳威人（但 Eywa 最终做到了）
- 人类的"背叛"让她暂时失去了判断力——她拒绝 Jake 不是因为他做了什么，而是因为"她感觉自己被骗了"

### 资源与人脉
- Mo'at（母亲——萨满）——精神导引
- Eytukan（父亲——族长）——在她父亲去世后，她的领导力负担增加了一倍
- Tsu'tey（未婚夫——她父母安排的）——在情感上是"她不想要的安全选择"

---

## 四、关系网络

### 与 Jake 的关系

Neytiri 的弧线围绕着对 Jake 的感情演变：

1. **救命→蔑视**（节拍 4）：救他的命只是因为木精灵选中了他。"你像一个婴儿——制造噪音，不知道做什么。你很勇敢——但愚蠢。"
2. **教导→尊重**（节拍 6-8）：在三个月内 Jake 从一个"婴儿"成长为一个战士。她开始看到一个她不想看到的东西：他在成为真正的纳威人
3. **相爱→结合**（节拍 9-10）：她选择了他——不是 Tsu'tey，不是她父母安排的安全选择——而是这个来自"天空"的"梦行者"
4. **被背叛→愤怒与心碎**（节拍 12-13）：Jake 承认自己是间谍——"你永远不会成为我们的人。"——这不是愤怒的宣言，是心碎的宣言
5. **再次信任→共同战斗**（节拍 17-22）：Jake 驯服 Toruk 后——她看到了"之前她看到的那个 Jake"还在——选择再次信任。在最终对决中救了人类 Jake："I see you"——这一次她在看他的"人类的脸"——她看到的不再是"天空人"，而是 Jake

### 与其他核心人物的关系
| 人物 | 关系性质 |
|------|---------|
| Mo'at（母亲） | 精神导引——Mo'at 是 Neytiri 要成为的"下一个角色"的模板 |
| Eytukan（父亲） | 父女。他的死亡是 Neytiri 最重的创伤 |
| Tsu'tey | 包办婚姻——她对 Tsu'tey 有感情但不是爱情。Tsu'tey 在死前接受 Jake，间接解放了 Neytiri |
| Grace Augustine | 最初不信任——但 Grace 死后，Neytiri 理解到"有些天空人是真心的" |

## 五、成长弧线

### 弧线类型
**信任弧线**——从"对所有外来者的不信任"→"信任一个外来者"→"被那个信任背叛"→"最终选择再次信任"。

这不是"成长"——Neytiri 本来就已经很成熟。这是"信任的修复"——比成长更难。

### 起点状态
一个自信、骄傲的纳威公主——对"天空人"只有蔑视："他们无法学习。"她的世界有明确的界限：我们是"人"，他们是"恶魔"。

### 关键成长节点

1. **木精灵落在 Jake 身上——"Eywa 选中了你"**（节拍 5）
   → Neytiri 放下了杀 Jake 的箭——不是因为喜欢他，而是因为 Eywa 的意志。她的信仰定义了她的选择。

2. **Jake 通过成人礼——她选择了他**（节拍 9-10）
   → 从"被迫教导"到"主动选择"——她打破了与 Tsu'tey 的包办婚姻——这是对她父母的意愿的抗争。

3. **Hometree 被毁——父亲被杀死、Jake 被揭示为间谍**（节拍 12-13）
   → 同时失去了父亲和爱人。这不是一个"转折"——这是整个世界的崩塌。

4. **Jake 骑 Toruk 降落在族人面前**（节拍 17）
   → Neytiri 看着 Toruk 降落的反应——既不是愤怒也不是喜悦——是"他做到了"——他知道 Toruk 是唯一能赢回信任的方式——而他做到了。她选择再次信任。

5. **杀死 Quaritch——第一次看到 Jake 的人类面孔**（节拍 22）
   → "I see you"——她在看着他的"真正的脸"——一个人类的脸——但她看到的是 Jake，不是"天空人"。这是整个三部曲中最重要的"看见"之一。

### 终点状态
- 失去了父亲、未婚夫和家园——但她获得了 Jake——不仅仅是作为伴侣，而是作为"她选择的未来"
- 在《阿凡达》的第一部结束时，她是 Jake 的伴侣和"他在纳威世界中的锚"
- 在续集中，她作为一个母亲和战士继续成长——但在第一部中，她的弧线已经完整了

## 六、语言与行为特征

### 说话风格
- 纳威语流畅且富有韵律——英语断断续续但意思清晰："You are like a baby. Making noise. Don't know what to do."
- "I see you"——每次说这句话的含义都不同：(1) 字面意思（我看到了你——一个外来者）(2) 情感（我接受了你——作为我的伴侣）(3) 救赎（我看到了你的真实的脸——你依然是 Jake）
- "Skxawng"（笨蛋）——她对 Jake 说了无数次——但每次说的时候她的语气从"鄙视"变成了"温柔的嘲笑"

### 习惯动作
- **嘶嘶声**（hiss）——纳威人的威胁姿态——她在教训 Jake、警告 Tsu'tey、面对 Quaritch 时都发出过这个声音
- **在战斗前将手按在心脏上**——对 Eywa 的简短祈祷

### 外貌细节
- 身上有仪式性的图腾纹路——标记她是萨满之女
- 战斗中的 Neytiri 和森林中的 Neytiri 完全是两个人——来自森林中机敏 → 战斗中极致凶猛

### 特殊癖好
- 在 Ikran 上飞行时发出呼号——这是纳威战士的"战嚎"
- 在与 Jake 的 Tsaheylu 中——她的眼睛闭上的瞬间——这是纳威人最私密的时刻
