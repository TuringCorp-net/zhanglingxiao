# 任务意图卡分析 — 《星际争霸》深度案例

> 游戏叙事的基本单元是"任务"（mission），不是"章节"（chapter）。
> 一个任务必须同时服务：(1) 玩家的乐趣（gameplay goal）(2) 故事的推进（story goal）(3) 新机制的引入/练习（player learning goal）。
> 这**三重目标**是游戏任务设计的核心——与小说章节和电影场景完全不同。

**M5 关键发现**：游戏任务必须同时有三个目标——story_goal、gameplay_goal、player_learning_goal。当前的 M5 意图卡只有 story 相关字段。对游戏叙事来说，gameplay_goal（"玩家在这个任务中在做什么？"）和 player_learning_goal（"玩家学到的什么会用于后续任务？"）是同样重要的。

**在这个任务的意图卡中，"必败战"作为一个独特的任务类型出现了——它是文学中'最终之战失败'在游戏中的等价物。M5 需要支持'必败/必胜'标注来帮助作者规划这种任务。**

## 五、M5 模板在《星际争霸》上的适配度总评

| 维度 | 适配度 | 关键发现 |
|------|--------|---------|
| goal（三目标） | ★★★★☆ | 对故事目标适用。但游戏任务需要额外的 gameplay_goal 和 player_learning_goal |
| structure | ★★★★☆ | 任务简报/任务中/任务后三段式适用 |
| foreshadowing_triggered | ★★★★★ | 与小说/电影相同——适用 |
| emotional_goal | ★★★★★ | **再次被验证**——游戏的情感设计是通过"玩家的行动"而非"玩家的观察"完成的 |

### 《星际争霸》特有的 M5 新增字段

1. **gameplay_goal**（游戏目标）：玩家在这个任务中在做什么？
2. **player_learning_goal**（玩家学习目标）：这个任务教会玩家的什么会在后续任务中使用？
3. **branching**（分支后果）：玩家的选择如何影响后续任务？
4. **mission_type**（任务类型）：必败/必胜/防守/进攻/解谜/护送/...
5. **estimated_playtime**（预计游戏时间）：替代 `estimated_words`
