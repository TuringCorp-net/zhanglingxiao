# 人物卡：Zeratul（泽拉图）— 黑暗教长

> 泽拉图是"悲剧预言者"原型的教科书级呈现——他看到了末日，用了一生去阻止它，在付出生命的代价后成功——但他没有活下来看到成功。

---

## 一、基本信息

- **姓名**：Zeratul（泽拉图）
- **身份/职业**：涅拉欣（黑暗圣堂武士）教长、先知
- **种族**：星灵（涅拉欣——被流放的黑暗圣堂分支）
- **年龄**：约 1000+ 岁（星灵的寿命极长）
- **在故事中的角色**：预言者 / 导师 / 牺牲者

---

## 二、弧线分析

### 弧线类型
**悲剧预言者型**——看到真相→被无人相信→付出一生尝试阻止→在成功的前夜死去。

### 起点状态（星际1）
黑暗圣堂的教长——他的族人被艾尔的主流星灵流放了数千年。当泽拉图在查尔与主宰发生灵能连接时，他成为了第一个"看到真相"的人——但这份知识是碎片化的——他只知道"某些可怕的东西在黑暗中等待"。

### 关键弧线节点

1. **母巢之战隐藏关卡——发现杜兰的混元体计划**（1998）
   → 泽拉图看到杜兰在培育虫族-星灵的融合体——"这不是凯瑞甘的阴谋——这是某个人利用这场战争。" → 他成为了系列中第一个知道"真正的敌人不是三族中的任何一个"的角色

2. **自由之翼——将预言传给Raynor**（2010）
   → 泽拉图收集预言碎片→读到主宰的临终记忆→向Raynor传达："凯瑞甘不能被杀死——她是唯一能阻止他的人。"
   → 在全宇宙都想杀死凯瑞甘时，泽拉图告诉Raynor必须救她

3. **虫群之心——引导凯瑞甘去泽鲁斯**（2013）
   → "Zerus。那是所有虫族的起源。在那里——你将找到你的真正的力量。"

4. **虚空之遗——牺牲自己救阿塔尼斯**（2015）
   → 阿塔尼斯被埃蒙通过卡拉控制——泽拉图冲上去——用他的曲光战刃割断了阿塔尼斯的神经索——**在阿塔尼斯恢复意识的瞬间——阿塔尼斯的手刺穿了泽拉图的胸膛**
   → 泽拉图死前对阿塔尼斯："我的使命终结了……你的刚开始。"
   → 泽拉图的死是阿塔尼斯从"忠实的继任者"变成"真正的领袖"的触发事件

### 终点状态
- 死亡——但在他的死亡中，完成了他的使命
- 他让阿塔尼斯觉醒——阿塔尼斯从此像泽拉图教导的那样领导星灵
- 泽拉图是《星际争霸》的"甘道夫"——导师在学生的战斗中倒下，但他的死亡让战斗变得有可能赢

## 三、核心台词

"命运在我召唤我之前就召唤了我。我愿意牺牲一切去完成我的使命。"
"我曾在黑暗中寻找光亮，却只发现了一线微芒。但为了守护它，我愿意付出生命的代价。"
"阿塔尼斯——不要忘记——我的使命终结了——你的刚开始。"
