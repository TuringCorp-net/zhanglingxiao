# 人物卡：Sarah Kerrigan（莎拉·凯瑞甘）— 刀锋女王

> 本文档以 Story Forger M3 人物卡模板逆向拆解《星际争霸》的核心人物——游戏史上最完整的角色弧线之一。
> 凯瑞甘的七阶段弧线跨越 17 年、5 款游戏——从受害者到加害者到救世主。

---

## 一、基本信息

- **姓名**：Sarah Louise Kerrigan（莎拉·路易丝·凯瑞甘）
- **身份/职业**：联邦幽灵特工（编号 24601）→ 克哈之子指挥官 → 刀锋女王（虫族主宰）→ 人类（被净化后）→ 原始刀锋女王 → 萨尔那加女神
- **年龄**：故事开始时约 25 岁，跨越多纪元
- **外表特征**：人类形态——红发、高挑、绿色的灵能眼；刀锋女王形态——虫族外骨骼覆盖、骨翼、昆虫式甲壳、尖锐的爪足；萨尔那加形态——燃烧的宇宙实体
- **在故事中的角色**：全系列的核心人物——横跨所有游戏的第一主角/反派/救世主

---

## 二、性格与动机

### 核心性格
被背叛的创伤→冷酷的战略家→为生存不择手段的人→被雷诺的"不变的好人"所触动→最终选择牺牲自己拯救宇宙

### 内在动机
- **童年**：灵能失控导致母亲脑血管爆裂死亡——父亲发疯——被联邦强制洗脑改造为幽灵特工
- **星际1**：被蒙斯克背叛——扔给虫族——"我不会忘记的"
- **母巢之战**：报复所有人——"如果世界对我是残酷的，那我就比它更残酷"
- **虫群之心**：复仇蒙斯克——"我要你看着我——然后你会死"
- **虚空之遗**：超越复仇——"这会保护所有人——包括我不想保护的那些"

### 外在目标
受害者→虫族征服者→复仇蒙斯克→阻止埃蒙→升华为萨尔那加守护无限循环

### 价值观与底线
- 对雷诺的爱——这是唯一贯穿她所有"版本"的东西。即使在最黑暗的母巢之战时期，她也从未真正伤害过雷诺（心理折磨但不杀）
- 不原谅蒙斯克——他背叛了她，杀了他全家，他必须付出代价
- 在虫群之心末尾，她放了Warfield将军的伤兵——"我不是怪物"

---

## 三、能力与限制

### 能力/技能
- **人类幽灵形态（星际1）**：顶级灵能——隐身、心灵感应、意念爆裂
- **刀锋女王（母巢之战）**：虫族的所有能力 + 人类的战略思维 + 灵能控制虫群
- **原始刀锋女王（虫群之心）**：以上所有 + 不受埃蒙影响 + 吸收其他原始虫族精华的能力
- **萨尔那加（虚空之遗）**：宇宙级的神力——创造/毁灭、操控虚空、超越物理法则

### 能力边界
- 童年创伤——被虐待和改造的历史让她对"信任"有永久性的障碍
- 被埃蒙的灵能波动"低语"影响——她在母巢之战时期的冷酷部分来自埃蒙对她灵能的微弱影响
- 没有雷诺的道德参照系——她在母巢之战中的背叛是因为没有人在她耳边说"这不是你"

| 关系 | 性质 |

## 五、成长弧线：七阶段循环

| 阶段 | 游戏 | 角色状态 | 弧线事件 |
|------|------|---------|---------|
| 1. **受害者** | 星际1人族 | 被联邦洗脑的幽灵特工 | 被Mengsk背叛——扔给虫族——"我永远不会原谅你" |
| 2. **被转化** | 星际1虫族 | 被装进蛹中 → 刀锋女王诞生 | 主宰选择她——不是作为工具——是作为"逃脱的棋子" |
| 3. **反英雄女王** | 母巢之战 | 背叛所有人——"我活在他们的背叛中" | 杀死菲尼克斯和杜克——Raynor的誓言：下次我会杀了你 |
| 4. **被净化** | 自由之翼 | 钥石剥离虫族基因 → 恢复人形 | Raynor射杀Tychus保护她——"她死了——我保护了活着的那个人" |
| 5. **复仇者** | 虫群之心 | 在泽鲁斯重获虫族力量（自由的重生） | 杀死蒙斯克——"这是给所有你背叛过的人的" |
| 6. **救世主** | 虚空之遗 | 吸收奥鲁斯精华 → 升华为萨尔那加 | 消灭埃蒙——"你的循环结束了" |
| 7. **归隐** | 结尾 | 以人形红发回到Raynor身边 | "准备好离开这了吗，牛仔？" |

### 弧线类型
**七阶段循环**——受害者→武器→救世主。以"被背叛的人"开始，以"超越复仇的人"结束。

---

## 六、M3 模板适配度评价

M3 模板可以承载凯瑞甘的七阶段弧线——但需要使用弧线类型为"循环型/多阶段型"。关键需求：**多阶段角色需要在"弧线"章节中增加"阶段"子条目**，每个阶段有独立的起点/终点状态和关键节点。当前 M3 模板只有一个"起点"和一个"终点"——对凯瑞甘这种7阶段的角色不够。
